# 团团碰碰乐

给灰色泰迪犬团团玩的 iPad 触屏小游戏。默认的小狗模式采用半写实灰色泰迪逐帧动画；爪子或鼻子碰中小狗后，小狗会爆开彩屑并消失，同时播放真实犬吠录音。

## 在线试玩

https://uau9.github.io/tuantuan-touch-game/

## 本地运行

```bash
python3 -m http.server 8080
```

电脑浏览器访问 `http://localhost:8080`。iPad 与电脑连接同一 Wi-Fi 后，可访问电脑的局域网 IP 地址，例如 `http://192.168.1.10:8080`。

## 游戏特点

- 小鱼、彩球、动画小狗或小鱼/彩球混合目标
- 小狗模式每次只出现一只灰色泰迪，外观、毛色和项圈保持一致
- 小狗使用带透明通道的 12 帧高清素材：行走、奔跑、起跳、腾空和落地均有独立动作帧
- 小狗是无矩形背景的独立角色，画面明显大于旧版，同时不会铺满屏幕
- 小狗会短暂停步观察并同步短叫，再突然加速、弧线跑动或跳跃，降低机械重复感
- 触碰后小狗会朝远离触点的方向受惊跃开并淡出，不再像图标一样瞬间爆炸
- 小鱼带有蓝黄条纹、圆点或波纹，会摆尾游动
- 小球带有条纹、圆点或环形花纹，会滚动并轻微弹跳
- 小狗沿八条左右交替的自然路线进入，以保证侧视步态与运动方向一致
- 碰中后躲开跑走，再从下一条路线进入；未碰中也会在跑出屏幕后自动换方向
- 慢速、中速、快速三档可选；移动速度、步态频率和再次出现间隔会同步变化
- 运动目标使用狗狗更容易感知的高对比蓝色、黄色与白色
- 音量可在 0～100% 调整，真实犬吠录音已做响度标准化，默认 90%
- 小狗模式使用短促的小型犬真实录音，并与停步观察动作同步；声音可在开始前关闭
- 无倒计时，可一直玩
- 目标较大，实际碰撞范围比图形更宽松
- 支持 iPad 横屏、竖屏
- 长按右上角才会暂停，减少宠物误触
- 切换到其他应用时自动暂停

在 iPad Safari 中选择“分享 → 添加到主屏幕”，以后从桌面图标打开即可获得无地址栏的全屏体验。

## 使用提醒

建议给 iPad 加贴膜并修剪宠物指甲，避免爪子直接刮伤屏幕。如果肉垫触控不灵敏，可以让团团用鼻子碰触。

逐帧小狗素材说明及真实犬吠录音的来源和许可见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。
